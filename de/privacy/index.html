Datenschutz

Diese Website verwendet keine Webanalyse und keine Werbe-Cookies. Schriften und Albumcover werden mit der Website ausgeliefert. Links zum Anhören öffnen externe Dienste erst, wenn Sie sie anklicken. Die MP3-Hörproben liegen in den Audioarchiven von Hans Gál und Simon Fox-Gál auf GitHub Pages. Audiodateien werden erst beim Abspielen abgerufen. Danach laufen die Hörproben weiter, bis Sie die Wiedergabe anhalten oder den Player schließen. Der Audiohost erhält die üblichen Daten einer Webanfrage.

Suche im Katalog

Suchbegriffe und Filter stehen in der Seitenadresse, damit sich eine Katalogansicht teilen lässt. Der Browser merkt sich Ihre Position im Katalog im Sitzungsspeicher, damit Sie nach dem Besuch einer Albumseite dorthin zurückkehren können. Die Position wird an keinen separaten Analysedienst übertragen und beim Schließen des Tabs normalerweise gelöscht.

Kontaktanfragen

Das Kontaktformular nutzt FormSubmit, um Ihren Namen, Ihre E-Mail-Adresse, Angaben zum Projekt und Ihre Nachricht an Simon zu übermitteln. Diese Daten dienen der Beantwortung Ihrer Anfrage. Laut FormSubmit werden Einsendungen 30 Tage lang gespeichert. Für den Versanddienst gilt dessen eigene Datenschutzerklärung. Die Empfängeradresse ist auf der öffentlichen Website nicht hinterlegt.

Das Formular zeigt an, ob Ihre Nachricht gesendet wurde. Schlägt der Versand fehl, bleibt Ihr Text im Formular erhalten.

Bitte senden Sie über das Formular keine vertraulichen Audiodateien, Zugangsdaten oder sensiblen Dokumente.

Hosting

Diese Website wird auf GitHub Pages gehostet. Dabei kann GitHub die üblichen Daten von Webanfragen gemäß seiner Datenschutzerklärung verarbeiten.
